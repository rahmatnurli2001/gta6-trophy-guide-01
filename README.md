An offline guide and tracker for all 55 Grand Theft Auto VI PlayStation 5 trophies: a checklist with saved progress, export and import, filters by kind and grade, a spoiler mode that hides story trophies until earned, a roadmap to the platinum, and a cited guide for every trophy.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080.
